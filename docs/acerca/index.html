El visor

Acerca

prezi-slides es un visor local de presentaciones espaciales: un árbol de frames en un lienzo 2D y una cámara que recorre un path. La fuente de verdad es texto en git. La UI no escribe coordenadas.

Contrato de agente: schema en schema/deck.schema.json, validador CLI y dos decks de ejemplo. No hay MCP ni editor visual. Se editan archivos y se corre run.sh validate.

  • run.sh validate [slug] — Ajv2020 + semántica
  • run.sh dev — visor en :4322
  • run.sh build y preview — HTML estático
  • run.sh video [slug] — MP4; Chrome en primer plano

Un tema editorial (papel crema, tinta, borgoña). Math con KaTeX en el build. El índice sale de loadAllDecks().
